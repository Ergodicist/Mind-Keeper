Mind-Keeper是推送重组算法引擎，旨在利用AI重构推送算法。

现有的推荐系统总是差强人意，不在于“算法不够准”，而在于**目标函数存在结构性偏差**。  
**下沉是社会基本趋势**：低质内容（煽动、空洞、情绪化）在生产成本和受众面上均占主导。任何不主动对抗低质内容的系统，都会自然收敛到以低质内容为主流构成。  
**推送窄化现象**：- 兴趣转移：用户变了，系统跟不上- 无效泛化：泛化探索总是落到低质热门（因为低质是主流）  
**后果**：用户体验持续下降 + 公众认知能力受损。这不是参数调优能解决的问题。需要重新定义推送的优化目标。

项目的核心理论支撑：**认知水平是对质量的深层建模，审美是对兴趣的深层建模。**  
核心推送参数的改变：  
用户：传统兴趣分类（喜欢什么） 转向  审美（觉得什么值得）+ 认知水平（能理解什么）   
作品：互动热度（点击/转发） 转向 审美品质（是否廉价煽动）+ 认知难度（信息复杂度）   
认知水平影响审美：你能处理什么层次的信息，决定了你能“看见”什么、被什么打动- 审美影响认知发展：你觉得什么“值得”，决定了你在什么方向上投入认知资源。  
经过训练的AI将承担初步评估的任务，加上用户反馈，我们相信新的评判体系将给出全新的结果。

**Mind-Keeper 不是“又一个”推荐算法**现有系统不断优化点击率、停留时长——我们选择停下来问一个不同的问题： **推送应该对谁负责**?  
我们的答案是：对所有人的心智与审美负责。
